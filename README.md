# موقع Abdelaziz Tamer (النسخة 2: كل حاجة بتتعدّل من الداشبورد)

- الموقع بيقرا كل المحتوى والإعدادات من Supabase (`config.js` فيه الرابط والمفتاح العام جاهزين).
- قاعدة البيانات اتجهزت بالفعل. الملف `supabase-schema.sql` للنسخة الاحتياطية بس.
- الأقسام (البراندات، النتايج، الشوكيس، الآراء) بتختفي لوحدها لحد ما تضيف محتواها من الداشبورد.

## النشر
1. ارفع محتويات الفولدر (مش الفولدر نفسه) على ريبو GitHub.
2. في Vercel: Add New > Project > اختار الريبو > Deploy.
